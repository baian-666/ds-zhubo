# IndexTTS-2.5 本机速度初筛

日期：2026-10-13。已实际运行，未接入助播，也未修改正式声音。

## 条件与计时口径

- RTX4070SUPER 12GB、Torch2.8.0+cu128、BF16 GPT、KV-cache 开启，CPU 参考编码器、6 个 CPU 线程。未启用 FlashAttention 加速引擎、torch.compile、DeepSpeed 或自定义声码器 CUDA 核。
- 用既有虚构台词的云端 claire WAV 作速度参考（约 9.48 秒），没有继续歌曲参考克隆或进行音色调参；这不是用户选定的小鲸鱼最终音色。
- 只加载一次模型，各文本/设置先单独预热，随后交替测量 3 次；两种设置使用相同文本、参考、对应随机种子和 CFM 25 步，区别是 num_beams=3/1。输出长度可能变化，不能将全部耗时差异归为纯运算优化，也未验收听感。
- 下表为模型生成首段完整 PCM 的中位数；常规样本各仅一个文本段，与整段生成时间近似。未包含识别、DeepSeek、HTTP、解码与播放，也没有测真实扬声器出声。音频能量起点代理另外记录，不当作语音识别或实际播放时刻。

## 测量结果

| 输入 | 默认 beams=3 | 较省计算 beams=1 | 默认音频时长中位数 |
| --- | ---: | ---: | ---: |
| 我在听，你继续。 | 1.90 秒 | 1.68 秒 | 2.43 秒 |
| 你来啦，今天有什么好玩的事情？ | 2.36 秒 | 2.12 秒 | 3.39 秒 |
| 等等，这个梗我接住了。你是不是又偷偷摸鱼了？别急，我先听你把故事讲完，再来帮你接下一句。 | 5.10 秒 | 4.56 秒 | 8.58 秒 |

本次模型加载约 11.96 秒，首次短句含参考处理约 6.69 秒（另有诊断同步开销）。不应每轮重新加载或处理相同参考。

默认中句的单次分阶段诊断：语音 token 生成约 1.36 秒、CFM 声学合成约 0.83 秒、声码器约 0.057 秒。同步计时会干预执行，仅用于定位，不混入上表普通请求。

长句 beams=1、文本 token 分段预算 25 的一次试验：首段 PCM 2.79 秒，第二段 5.59 秒，全部生成约 5.59 秒；未分段普通试验约 4.56 秒中位数。文本和种子/生成长度口径不同，该结果用于说明提前供给与总耗时取舍，不算严格控制变量的加速比例或连续播放验收。上游是逐文本段返回，仍须完整生成该段语音；不是逐音频帧输出。

CUDA 峰值分配约 3.5GiB，不含所有外部程序/驱动占用。试验进程完成后已释放模型，未停止用户其他应用。三次初筛不足以推导稳定 p95、整场可靠性或最终音色的同等性能。

## 判断与下一步

减少 beams 的等待差异约一成，且会改变生成结果；这轮不是 FlashAttention/vLLM/TensorRT 加速验收。短句仍约 1.7 秒才有 PCM，完整对话另有识别/模型等待，尚未证明适合快速接梗。应先对主要语音 token 生成瓶颈验证 Windows 可用的加速路径，再决定是否转 Aqua；不先创建新音色、降级模型或安装多套服务。

结果：忽略目录 `data/indextts/speed-20261013-r2/report.json`、`validation.json`、28 条 WAV 与各阶段日志。18 条普通测量、6 条预热、1 条首次参考、3 条诊断/分段试验。音频格式/有限值/非静音/峰值/时长/哈希及参考未改检查通过；工具不能听音，音质需独立试听。
