# 三条语音路线对比

日期：2026-10-13。已有本机/真实云端试验，正式直播语音接入另行验收。

## 实测速度

RTX4070SUPER 12GB。每组 3 次暖机请求，下表为首 PCM 中位数。Aqua/Index 是模型侧可用 PCM；Qwen 包含云端网络与本机 HTTP 到达，已经复用连接。不是纯模型公平排名，也不是识别到扬声器的完整交互延迟。

| 台词 | Aqua V3 本地 | Qwen 云端流式 | IndexTTS-2.5 本地 beam=1 |
| --- | ---: | ---: | ---: |
| 我在听，你继续。 | 0.323 秒 | 0.667 秒 | 1.68 秒 |
| 你来啦，今天有什么好玩的事情？ | 0.230 秒 | 0.677 秒 | 2.12 秒 |
| 等等，这个梗我接住了……先听你把故事讲完（相同长台词） | 0.299 秒 | 0.671 秒 | 4.56 秒 |
| Qwen 试听页的三句台词 | 0.192 秒 | 0.641 秒 | 未测 |

Aqua 与 Index 使用同一现成 claire 虚构中文讲话参考；Qwen 为 Vivian 系统声线。Aqua 按标点切分、V3 声学帧增量输出；Index 普通样本整段生成，另有一次长句文本分段首 PCM 2.79 秒，不能把三者当作相同解码机制或相同音质。Aqua 首块均通过 10ms RMS>=-45dBFS 活动检查，但这仍不是语言识别或实际可听首声。Qwen 新测 12 条均复用连接，历史新建连接的页面请求首 PCM 4.35 秒。

后续用户听审发现日语参考克隆中文有错读且语速过快。核对发现上述Aqua fast预设同时强制1.3倍语速、4步声学采样；此前漏列这项语速设置，不能据表宣称正常语速/同等音质下的优势。当前服务已移除fast预设，明确使用0.9倍/16步；新日语参考欢迎句由3.49秒变为4.33秒，但仍有可疑错音，尚未完成音质验收。同参考/同台词的Index隔离对照已生成，两句中的调侃句独立ASR全文匹配，欢迎句称谓有同音/近音转写差异。当前正式试验后端仍Aqua，Index未接入；最新质量反馈及实测见STATUS首节。

Aqua 短/中/长/三句的全部生成中位数为 0.85/1.24/4.29/3.38 秒，对应音频时长 1.53/2.25/6.87/5.57 秒；Qwen 为 1.05/1.16/2.16/1.99 秒，音频时长 2.08/2.64/8.16/7.20 秒。Aqua 先出声更早并不代表全部生成更快。帧间隔与缓冲是否足以稳定播放仍须接入后验证。

## 实用取舍

| 方面 | Aqua / GPT-SoVITS | Qwen 当前云端路线 | IndexTTS-2.5 |
| --- | --- | --- | --- |
| 当前优势 | 本机增量音频很早可用，适合进一步试自然接话 | 已能直接选系统声线，部署最省事，整段返回快 | 明确情绪向量/参考控制，现有隔离环境已运行 |
| 音色定制 | 参考音频与对应台词；本次为 V3 基础模型测试 | 当前试听只有系统声线；定制音色需另接对应服务 | 基础声线来自参考，当前没有文字创造全新声线的常规接口 |
| 情绪 | 声音权重与参考语气很关键，Aqua 主要优化执行；尚未验证自动情绪切换 | 当前稳定模型试听未加情绪指令/音色设计；不能把其他 Qwen 模型能力说成已接入 | 情绪向量已用于早期试验，但最终声线未获用户认可 |
| 开销 | GPU 常驻、本机编译/包兼容成本，初筛峰值 CUDA 分配约4.65GiB | 需要网络和云端额度，需提前建连及连接复用 | 本机 GPU/参考缓存，当前基础配置首音频较慢 |
| 当前听感结论 | 16 条 WAV 已生成，待用户试听 | 12 条新 WAV、页面试听已运行，偏好由用户决定 | 已有用户不认可的歌曲克隆；本次速度参考不代表最终声线 |

当前建议：优先把 Aqua 的增量输出接入实际小鲸鱼试聊，Qwen 保留简便的备选；Index 先作为明确需要情绪控制或音质对照时的候选。用户随后提供新的清晰游戏角色对白后，才测试那份音色；不恢复旧歌曲克隆。最终选择以同场景真实对话的音质、首声、连续播放和打断为准。

## 接入后的补充测量与入口

已实现共享 AIRI 的增量播放适配和真实声音选择：两端“当前配置→小鲸鱼的声音”可选择 Aqua、Qwen 和原有硅基流动，Qwen另可选系统声线。配置写本机忽略的 .env，失败保留旧配置，发言中不允许更换。字幕保留完整句子；只有句子最后音频块播完才推进历史。明确打断取消本机/云端请求并丢弃迟到块，句子及请求顺序保持一致；Aqua工作器结束上一段时有短暂忙状态，下一段有界等待释放。

真实 Aqua 服务经过生产 cohost 语音路由的模拟语音场景验收：实际模型与HTTP，ASR/LLM文本/播放回执为模拟。桌面与临时网页预览运行时短句首PCM 1.36/0.63/0.96秒；关闭本轮临时网页后，三次为0.643/0.871/0.460秒（中位0.643秒），模型内计时0.639/0.867/0.456秒，转发差约4ms。观察条件、随机生成及缓存与独立基准不同，不能把变化全归为显卡竞争，也不能把独立0.2秒直接报成日常开口时延。没有真实ASR、DeepSeek或扬声器计时，仍待用户试聊。

本机主入口可双击根目录“启动小鲸鱼.cmd”；它复用已有联调服务，再打开桌面开发入口。Aqua冷启动由声音准备过程启动已安装本机运行包，不自动下载新模型；参考音频与台词可通过忽略 data/aqua-tts/reference.json 指定。初筛使用 claire 虚构台词参考；当前新日语参考的接入情况见下段。

随后用户提供日语游戏对白并授权转写，已切换为新参考：原录音3.30–9.20秒连续5.90秒、日语参考台词、中文生成。SenseVoice与本机Whisper small交叉核对候选句的发音一致，未作人工逐字听审。默认参考语言兼容中文，新profile指定promptLanguage为日文；需安装固定日语前处理依赖。新参考四条中文试听首PCM为0.703/0.514/0.482/0.485秒，桌面运行条件，均单次，不能替换上表同台词三次中位数。生产助播路由的一次短句首PCM1.079秒，ASR/LLM/播放回执仍为模拟。试听与详细审计在忽略data/aqua-tts/reference-20261013-user；本轮未重新比较三种引擎音质或调节独立情绪参数。

检查：npm run check/npm test 160项；AIRI音频包58项、包类型/构建、网页与桌面类型检查通过；改动文件ESLint0错误、Stage.vue原有7个注释长度警告。全仓类型检查仍被 scenarios-stage-tamagotchi-browser 缺 vue-tsc 阻断，全仓lint仍因既有 @radix-ui/colors 缺失退出，未标为通过。桌面启动日志与网页声音选择已验证，桌面窗口随后正常退出；未将网页截图或模拟回执说成完整桌面真人语音验收。
