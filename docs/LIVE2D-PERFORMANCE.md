# 小鲸鱼与 Live2D 表演第一版

更新：2026-10-10。范围为本机 stage-web，使用当前默认 Live2D 模型。

## 直接试用

打开 http://127.0.0.1:8787 。舞台下方显示“角色已连接”后，点“轻笑”“嘴硬”“点头”直接看动作。
动作约三秒后恢复；“恢复”或“打断助播”可提前停止。

右侧选择 DeepSeek。人工模式输入“小鲸鱼，蓝色大肥鱼这个名字适合你吗？”，点“人工让助播接话”。
自动模式开启“自主参与”，可输入“你先别开口，只在聊天里给个表情，我还有后半句”。
选择何时参与仍由模型和话轮程序共同判断，不保证每个场景都选同一个动作。
导演与回复共用“小鲸鱼”名称和头像；非语音回应气泡标为“文字 / 表情回应 · 不开口”。

## 已实现

- 两种导演模式共用小鲸鱼人格。改编来源是 qq-bridge 的 roles/小鲸鱼.md，固定提交 9df6a7e7fc5abcb36793337f778483bd442a3d2d。原 MIT 许可保留于 third-party/qq-bridge-LICENSE.txt。
- 保留短句、嘴硬、接梗、认真时收起玩笑等特点。调整 QQ 节奏、工具与事实规则，直播中优先主播，不假装搜索、真人经历或蓝发鲸尾画面。
- 自主 participate 工具增加 react 与 performance 字段。一次判断同时决定等待、接话、停止或非语音回应，以及姿态。react 最多 40 字，可只发 emoji，也可仅有姿态，受现场、静音和主动冷却限制。
- 明确交棒仍直接流式回答，允许开头带一个短动作标记。解析器跨分片提取白名单动作，不把标记写进字幕或已交付历史。模型可省略标记，程序不会凭关键词假称模型选择了动作。
- 姿态支持待机、倾听、思考、点头、轻笑、惊讶、嘴硬。程序按话轮状态显示倾听或思考，按模型意图短时表演。当前动作使用通用参数姿态，不是新绘制形象或模型专属动画。
- 打断、静音、换话题、换模式与有效新讲话清除旧动作；过期自动释放。回答取消只清除本话轮，旧话轮取消不能清掉新动作。舞台断联约 1.5 秒释放控制。
- 表演不增加第二次模型调用。流式动作标记有少量输出开销；没有做严格延迟 A/B，不能声称完全零延迟。
- 修复旧候选消费请求清除新候选的问题，并扩展“小鲸鱼”点名的直接交棒路径。其余可靠性待办保持登记。
- AIRI 变更的可重放源码与安装器在 integrations/airi 和 scripts/patch-airi.mjs，dev:airi 自动应用。没有新增 MCP 服务或展示模型思维链。

## 已测结果

- npm run check 与 npm test：68/68 通过。
- stage-web typecheck：通过。AIRI 修改文件的 moeru-lint：通过。复用的 Live2D motion-control Vitest：6/6 通过。
- 全量 pnpm lint 已运行，但被 AIRI 文档站未安装的 @radix-ui/colors 阻断；不是全量检查通过。
- Edge 浏览器：轻笑和嘴硬实际渲染截图确认，点头控制、过期、手动打断、心跳中断后释放通过，页面错误为零。证据保存于忽略的 data/performance-*.png 与 JSON。
- 真实 DeepSeek 排练：1 次快速流式生成、2 次自主判断。首次回复“？你再说一遍，是小鲸鱼”并选择 pout，首字 813 ms；请求先别开口时只发 🙃，判断 1224 ms；认真提问时回复并选 listen，判断与拟稿 1291 ms。后两次没有第二次生成调用。
- 收尾真实浏览器再测一条“小鲸鱼”回复，公开文字“？你再说一遍”，首字 267 ms，未输出显式动作标记。该次证明人格与界面流程，不算该句自主选动作通过。

这些是文字排练、独立浏览器和默认模型结果。未验收真人无脚本直播、真实语音、口型、其他模型、Electron 或完整多标签控制权。
