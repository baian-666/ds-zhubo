# 独立头身拼接预览

用户提供 `大肥鱼.zip`，希望保留旧模型的头与表情，采用新模型的身体。两个档案均只有运行数据，没有 `.cmo3` 或分层 PSD。因此本次做运行时图层组合，未生成合并后的单一 Live2D 模型。

## 使用

双击根目录“打开拼接预览.cmd”，或运行 `scripts/start-compose-preview.ps1`。页面是 http://127.0.0.1:8790/ 。依赖本机已安装的固定 AIRI 依赖和 Cubism Core。

原包默认位置为用户给定的 `D:\edge_download\大肥鱼.zip`。换位置后给启动脚本传 `-Archive`。旧头部使用之前准备好的 `data/live2d/whale-airi.zip`。原 ZIP 不改动，解压副本和构建输出只保存在忽略的 `data/compose-preview`。

页面可切换拼接、旧模型去桌面和道具、旧完整模型、新完整模型，可试转头、轻摆身体、模拟口型和笑眼。直接查看去道具版本：http://127.0.0.1:8790/?view=old-clean 。四个滑块调整比例与位置，只影响预览；头部滑块仅用于拼接。“保存本机调整”写此预览来源的浏览器存储，不写 AIRI 角色设置。关闭页面不会停止正式助播。

预览不访问助播 API，不开麦，不使用 DeepSeek 或语音服务，不更改桌面/网页版当前角色。它只在本机 8790 端口提供白名单页面和两个模型的资源。

## 实现与限制

- 使用 AIRI 已安装的 Pixi Live2D 渲染库和 Cubism Core，不修改 AIRI 源码。
- 去道具模式只渲染原模型，隐藏实际核对的桌面、桌面图标、点餐板/夹子、笔与甜品网格，保留单独的手指、袖子、衣服、头发和尾巴。甜品与握杯的小手指同在 ArtMesh103，会一起隐藏；原持物手势保留，没有重新绘制空手姿势。原身体是 Q 版半身，没有可通过隐藏桌面显示的完整腿脚。图层过滤只发生在绘制期间并恢复透明度，切回旧完整模型可恢复所有道具。
- 按这两个模型的实际网格 ID 过滤图层：旧后发放在新身体后面，旧脸、前发和两侧头发放在前面。新模型的头发、脸和眼睛隐藏，旧点餐板、手、桌面和尾巴隐藏。
- 为处理后发遮挡，旧头部模型有前后两个渲染实例，共三个模型实例。它比单模型占用更多资源，尚未做持续直播性能验收。
- 使用新身体脖子网格的位移修正旧头部位置。预览只校准小幅动作，不支持任意大角度无缝匹配，也没有重新绑定网格、重画接缝或统一两套模型的美术风格。
- 笑眼与普通眼睑同时切换，避免两套眼睛叠加。预览只提供一种表情示范，未验收旧模型全部 44 个项目。
- 图层 ID 和配准只针对当前两个运行包，不能直接套到其他模型。源码保存于 apps/compose-preview，启动与构建由 scripts/compose-preview.mjs 完成。

下一步由用户判断头身比例与画风，再决定是否细调和接正式 AIRI 舞台。真正导出单模型仍建议获取源工程后在 Cubism 合并。
