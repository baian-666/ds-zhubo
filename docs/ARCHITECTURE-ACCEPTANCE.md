# 架构升级验收与边界

更新：2026-10-15。当前目标是完成既有桌面直播功能的架构整合，不把未来 VRM、长期记忆或新语音引擎列为本次完成条件。

## 当前结构

- AIRI 承担桌面/网页、原生设置与角色卡编辑、模型资源和实际音频播放。
- 本地 Node 运行时承担现场、参与判断、回复、交付确认、配置仓库、场次记忆和任务取消。
- 契约位于 `packages/cohost-contracts`；鲸鱼参数映射留在 AIRI 表演适配器。没有新增对话模型调用、第二个发言调度器或微服务。
- SQLite 保存普通服务配置、角色目录、当前角色与场次；模型/图片/音频是本机资源，密钥仅在忽略的 `.env`。

## 本轮收尾

| 项目 | 已实现行为 | 验证 |
| --- | --- | --- |
| 回复模型 | AIRI 意识页展示和修改实际 DeepSeek 模型；导演与回复使用同一配置；验证模型访问权后原子保存 | 正常保存、重启恢复、旧版本冲突、取消、写入失败和实际模型目录访问 |
| 语音识别 | AIRI 听觉页展示实际 SenseVoice/SiliconFlow 与密钥配置状态，共用原生麦克风选择；下次开始收音生效 | 隔离浏览器页面与现有媒体回归；未启动真人麦克风 |
| 声音 | AIRI 发声页复用既有 TTS 配置仓库及同链路试听；删除设置页固定轮询 | 静止页面无重复配置请求，原有播放与打断回归 |
| 人设 | 原生卡编辑器读写版本化角色目录；当前角色和绑定状态持久化；陌生扩展字段往返保留 | 两个独立浏览器窗口互改、真实 Pinia leader/follower、SQLite 重启/故障/冲突 |
| 角色切换 | 同卡改人设不截断正在说的话，撤销旧候选判断；切换身份取消旧角色输出；关舞台保留身份、释放实时能力 | 后端契约测试与媒体回归 |
| 本机形象 | 自动导入不再把随机资源 ID 当角色编辑写回；外端未安装的模型 ID 不覆盖本机舞台 | 两窗口无回写循环、原生 store 的缺失资源回归 |
| 配置失败 | 不静默重置或用旧窗口覆盖；角色草稿保留，显式重新读取前备份本地草稿 | 真实 SQLite 故障、修订冲突、导入中修改保护 |

直播模式的角色卡不再展示无效的每卡聊天/视觉/语音供应商覆盖项，改为进入实际服务设置；原字段仍保留，普通 AIRI 模式保持原生用途。当前只支持已经接好的 DeepSeek 和 SenseVoice 适配器，不宣称 AIRI 所有供应商都可直接使用。

角色目录同步不复制模型/贴图/表情包素材。表情许可仍由 AIRI 按模型保存，舞台发布有效能力和授权，运行时和执行器同时校验。关闭舞台后不恢复过期控制权。

## 架构路线中的具体取舍

- 控制采用鉴权 HTTP，状态采用带版本/续接的共享 SSE；音频保持独立流，Electron 演出继续使用原有桥。现有需求不再为了统一协议名称额外迁移 WebSocket。
- 服务端有限的状态聚合、租约和调度时钟保留；删除的是界面重复整份轮询，不是正常音频/动作时钟。
- 当前任务都是有界异步 I/O，已经整理归属、取消与迟到结果；只有将来增加 CPU 重任务时再加 worker。
- 当前继续以固定 AIRI 提交、受跟踪的 `integrations/airi` 和可重复补丁为唯一修改来源。派生 Git 分支留到真正升级上游时评估，不同时维护两个可写来源；本机固定构建、源码检查点和数据库备份提供恢复入口。
- B 站仍通过已接好的 blivechat 本机入口配置，身份凭据不迁入普通角色仓库；不为尚未开播验收的接口增加另一套 SDK。
