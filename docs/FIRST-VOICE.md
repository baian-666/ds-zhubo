# 首声链路：逐条交付参与结果

本批目标是降低文字输入/ASR结束后的首声等待。保持 DeepSeek、人设、IndexTTS 音色和采样配置，不添加填充语或第二次前置模型调用。

## 链路与边界

- 明确交棒仍走原有直接流式回复。
- 自动参与改用一次流式 `participate` 工具调用。`records` 第一条同时包含完整的参与决定、目标、公开理由和首句。程序完成 JSON 解析和现场权限复核后，才允许进入发言话轮。
- 后续 `speech` 记录逐句交付，并可提交一次 `presentation`。建议台词之后编排表情、组件和表情包，不阻挡首句合成；完整表演记录出现在两句之间也允许。动作沿用既有范围检查、原生表情权限和本轮表情包目录。
- 等待、非语音反应和停止仍需完整调用完成后执行，不从半截 JSON 猜动作。只接受一个工具调用、一个决定，文本总长800字、每条160字、记录最多10条、参数最多24000字符。
- 首句前保留4.5秒判断时限，一次模型请求总时限30秒。决定流由待判断任务移交候选，再移交实际话轮。新现场、过期、拒绝、打断和关闭会释放对应网络流，不重试生成另一份答案。
- 后文只能延续首条决定。重复的目标/行动字段必须与首条一致，不能换目标或改发言许可；可选表演只读取已知能力，未知字段与额外表演不执行，避免错误动作中断正确台词。
- 若首句之后发生断流/截断/协议错误，结束本轮并显示失败，已播放的完整前缀按原回执进入历史。已说出的首句无法撤回，不把它伪装成一次完整成功。
- 真实试跑发现模型偶尔漏掉外层包裹的 `]`、`}`。只在所有记录都已完整解析、外层没有其他内容且服务端正常结束时补齐这些闭合符。它不修补决定/台词/动作内容，仍拒绝待填写的逗号、额外字段、残缺动作及异常结束。

## AIRI 播放衔接

后端通过原媒体心跳附带 `speechBoundaries`（本话轮原文的 UTF-16 偏移）。应用根媒体宿主把这些完整记录交给现有 `writeLiteral` / `writeFlush`，继续使用 AIRI 分句、合成队列、播放、字幕和口型。

旧分句器为合并重复标点和 Unicode 组合字符，会等下一个字符。现在保留原文的路径识别明确 flush 控制符，完整记录无需等下一句。普通未提交文本仍保留跨块字符及标点检查，flush 不进入字幕、TTS正文或历史。

## 测量和回归入口

- `scripts/benchmark-first-voice.mjs --pairs=30`：真实 DeepSeek＋正在运行的 Index；三种场景轮换，新旧路径交替顺序。相同人设、模型、运行包和分句器，参考预热后记录模型决定、首个PCM等时间。不同调用的自然台词不保证相同，需要结合原始记录看待长度差异。输出在忽略的 `data/first-voice-benchmark/`，不保存密钥。
- 这个基准从模型请求开始计时，不含麦克风/ASR、输入防抖、桌面调度或扬声器硬件时间。全链路另看实际桌面 `playbackScheduledReceiptAt - inputAt`，它也只是软件调度回执。
- `tests/participation-stream.test.mjs`：完整记录解析、分片、单工具、取消、过期、后续错误、一次请求交付。
- `scripts/media-lifecycle-smoke.mjs`：真实浏览器＋模拟LLM/PCM，证明后续生成被挂起时首句已开始播放，并继续验证导航、关麦、标点和打断。不代表真实模型速度或音色听审。
- `integrations/airi/tts-source-text.test.ts`：完整句、有无标点、重复标点、UTF-8与组合字符分片。

首轮30组用于发现问题：3次新路径外层闭合失败，取消中的Index任务还影响了2次紧随其后的旧路径。此轮不作为发布性能结论。原始数据保留在 `data/first-voice-benchmark/initial-with-envelope-failures.json`。修复后重新测量，并在每次计时前确认共享worker空闲；其他项目排队时间不计入该基准。

## 2026-10-15 验收

最终30组对照，旧路径30次、新路径30次，全部成功。测试时后台有游戏进程，不能作为空闲机器的上限。每组交替先后顺序，使用固定小鲸鱼人设、三条测试输入、空历史和相同表演权限。不同调用的自然台词有变化；首个合成片段平均长度旧9.8字符、新10.0字符。

| 可交付首句 P50 | 1.619秒 | 1.200秒 |
| 可交付首句 P95 | 2.687秒 | 1.636秒 |

实际固定Electron另外完成两次自动参与聊天，点击到软件播放调度约13.372秒、10.262秒，两条45字回复均全部完成播放，麦克风关闭。对应TTS请求到首PCM约11.555秒、8.410秒；首PCM到播放调度约34ms、37ms。实际播放链路通了，但尚未达到顺畅实时交谈的速度，主要剩余耗时在本地合成。需要单独验证不同资源负载和Index推理优化，不能把历史空闲时1.7秒首PCM套用于本轮场景。

## 回退

在本机 `.env` 设置 `PARTICIPATION_STREAM=0` 后重启后端，即恢复完整决定后发声；不更换音色，不影响共享 Index 进程。新的桌面仍能播放此路径。

旧桌面可以忽略新增句界字段，但不能保证流式首句立刻合成。后端与桌面一起更新，日常入口仍为“启动小鲸鱼.cmd”；固定构建支持保留上一个版本。源码与可重放覆盖位于 `apps/cohost/`、`integrations/airi/`、`scripts/patch-voice.mjs`。
