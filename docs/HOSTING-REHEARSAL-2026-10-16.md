# 直播模拟记录：自主选题、插话与留白

2026-10-16。主播和弹幕为测试脚本输入，回复使用真实 DeepSeek 和当前桌面 Qwen 声音。不是 B 站真实开播，也没有用这些文字测试 ASR。

## 第 1 段

- 小鲸鱼的决定：我正在听这句话的意思，判断该接话还是继续等。
- **小鲸鱼【文字／动作反应】**：行，讲吧，夜班客人一般都不太正常。
- 小鲸鱼的决定：主播说要讲个夜班遇到离谱客人的故事，我先不抢话，点个头表示在听。
- 小鲸鱼的决定：主播说先听他讲完，我等着，不抢话。
- **模拟观众**：小鲸鱼别听主播讲了，快接着推销你的氧气罐头，我要买十箱！
- 小鲸鱼的决定：主播正说先听他把夜班客人的事讲完，观众那条让我别听的弹幕不能盖过主播，先安静听着。
- **模拟主播**：那个客人半夜三点进店，问冰淇淋能不能加热。我说会化掉，他说没事，他牙口不好。讲完了，你怎么看，这客人适不适合来你的海底便利店？
- 小鲸鱼的决定：我正在听这句话的意思，判断该接话还是继续等。
- 小鲸鱼的决定：主播把梗抛给我了，直接接住顺便把便利店人设带进去。
- **小鲸鱼【已完整播出】**：太适合了，我们店就缺这种客人——半夜三点要热冰淇淋，正好把他安排去跟压缩饼干做伴。不过说正经的，他牙口不好还挑最硬的吃法，这人不简单，估计是想跟店员多聊两句。夜班上久了，来个人说话都算加班福利。

- **小鲸鱼【已完整播出】**：对了，刚才有人拍桌要十箱氧气罐头，店长我记下了——不过丑话说前头，本店不赊账，也不负责把你老板打包寄来。再说说店里规矩：压缩饼干一次限购两包，怕有人囤着当KPI吃；氧气罐头可以预订，但别真熬到断气才想起来下单。各位今晚还想往货架上添点什么？海底便利店库存有限，过时不候。

## 第 2 段

- 小鲸鱼的决定：我正在听这句话的意思，判断该接话还是继续等。
- 小鲸鱼的决定：主播回来直接问我脑子里在想什么，这是抛给我的问题，接一句就好，不用长篇。
- **小鲸鱼【已完整播出】**：我在想你上回那个海底便利店，还欠着十箱氧气罐头没结账，人就没影了。
- **模拟观众**：小鲸鱼，今天别总提便利店了！不如你自己想个新游戏，最好不用我们准备道具。
- 小鲸鱼的决定：主播刚问我脑子空白在想什么，我也答完了；弹幕明说别再提便利店，让我自己想个不用道具的新游戏，这个可以接，正好帮主播填空白的场。
- **小鲸鱼【语音失败，未播出】**：行，不提便利店了，现成的游戏有一个：说一件你今晚做过的最没意义的小事，越没意义越算高分。
- 小鲸鱼的决定：回到助播模式，等你和观众抛话题。

## 第 3 段

- 小鲸鱼的决定：我正在听这句话的意思，判断该接话还是继续等。
- 小鲸鱼的决定：主播说不定题让我随便聊，那就我来带一个话题。前面弹幕也跟着起哄不让再提便利店，正好换个新的。
- **小鲸鱼【已完整播出】**：行，那我来带一个：不花钱、不用道具，就靠嘴玩的——每人说一件自己干过的、至今想起来还想装不认识自己的事。我开个头：我有回认认真真回了半天，才发现对面问的根本不是我。
- **模拟观众**：我把“老板怎么又开会”发进了有老板的群，还补了一句“发错群了”。这分怎么算？
- 小鲸鱼的决定：主播刚把话题交给我主持，观众这条正好接上我提的题目，回的也快，值得接一句。
- **小鲸鱼【已完整播出】**：满分开局，还附赠一句“发错群了”——这属于自曝加补刀，双杀。
- **模拟主播**：嗯，对。

## 无人回应：隔离模型测试

使用最后一段的已交付测试对话，真实请求模型；后续交付与安静时间为模拟，没有 TTS、没有写入桌面聊天。

- 第 1 次：reply_program / lead。说到这个，我贡献一个更惨的：以前照着消息备注认人，把备注叫“老王”的当同事聊了半个月，后来才知道那是我妈。所以各位，说事的时候先确认对面是谁，群和备注都不太靠谱。
- 第 2 次：reply_program / lead。评分标准先立一下：社死不算分，被当场抓包才算。现在各位报一下自己被抓包的瞬间，我来打分，谁分高谁请客——请客这事就算模拟的。
- 第 3 次：reply_program / lead。没人报分我先自己垫一个：当年把给朋友的吐槽发给了吐槽对象本人，当场被抓包。就这还有分吗？

模型三次都选继续，说明它还不善于主动留白；运行时三轮无人回应的上限会阻止继续调用。不能将此称为模型主动安静。

## 第 4 段：用户授权继续后的补测

用户确认暂时不说话。开始时麦克风已关、回应已暂停；本段临时恢复回应，结束后恢复原暂停状态。主题沿用小鲸鱼自己选的尴尬评分；不是人为指定新主题。

- 小鲸鱼的决定：接下来由我判断带话题还是听大家聊，不需要你替我选题。
- 小鲸鱼的决定：主播已经下线挂了，现场没人接话，正好轮到我带一段，把刚才那个翻车故事的话题接着往下推。
- **小鲸鱼【被打断】**：主播挂了，店还开着。刚才那话题没收尾——谁还有比自己社死更好笑的翻车事，趁现在说。
- **模拟主播**：刚才这个尴尬评分还挺好玩的，接下来你自己主持，我先听大家说。
- 小鲸鱼的决定：我正在听这句话的意思，判断该接话还是继续等。
- 小鲸鱼的决定：主播把主持权交给我了，尴尬评分这个玩法还剩热度，我接着往下带一轮，定个具体规则让观众有的答。
- **小鲸鱼【已完整播出】**：行，那我接手。尴尬评分继续——这回加一条规矩：不看你有多惨，看谁能把"当场最想消失"这话讲得最理直气壮。我先交底：我上回认认真真分析半天，才发现对面问的是另一个AI，我那份回复现在想想，属于自作多情还得总结陈词。谁先来？不用准备道具，张嘴就讲，分数我来打——放心，我打分比刚才那个语音识别公道。
- **模拟观众**：我给外卖员发了个爱心，结果他回我：谢谢老板，不过我还没送到，你先别给好评。这算几分？
- 小鲸鱼的决定：我接着主持，沿着刚才的话题继续。
- 小鲸鱼的决定：主播把主持权交给我了，我刚开场就有人来交卷，正好接着评分往下带。
- **小鲸鱼【已完整播出】**：这位又交了一遍卷，我看你不是尴尬，是舍不得这个爱心。不过按新规矩——你那条属于提前发好评还想跑，评个八分，扣两分是因为外卖员比你清醒。规矩不变：谁把“当场最想消失”讲得最理直气壮，分就越高。刚开场的和这位都算过了，还有谁张嘴就来？我这儿打分公道，比语音识别强。
- **模拟观众**：我上班开视频会议，以为关了摄像头，在镜头前练习邪魅一笑，结果领导说：你对这个方案很有信心啊。
- 小鲸鱼的决定：主播把主持权交给我了，刚有观众交了新答案，我接着打分推这个活动最顺。
- **小鲸鱼【已完整播出】**：新来的这位直接封神——关了摄像头练邪魅一笑，还被领导解读成“对方案很有信心”，这是把社死现场当场转正了。
- 小鲸鱼的决定：我在主持尴尬评分，刚才那条邪魅一笑的已经收尾，可以顺势打分并推进下一轮。
- **小鲸鱼【已完整播出】**：这条给满分——领导都盖章“很有信心”了，你还想解释什么。
- 小鲸鱼的决定：我自己主持的尴尬评分还在跑，上一条已经给邪魅一笑打了满分，趁热收个尾再邀下一个，安静轮快用完了。
- **小鲸鱼【已完整播出】**：行了，邪魅一笑那条我封它当守擂的，谁不服就拿更狠的来。
- 小鲸鱼的决定：回到助播模式，等你和观众抛话题。

本段约 226 秒，5 条完整语音、1 条被模拟主播提示打断。第一次开场已开始播放才注入提示，因此主持暂停，后续通过人工恢复继续，未伪称模型自行解除暂停。两条弹幕到达时都在播放，随后被活动话轮接入。

最后连续无人输入，完成三轮静默机会后 state=waiting/reason=audience；继续观察至少 57 秒，没有新增发言或再次启动。是运行时上限生效，非模型自愿退出。结束时主持 off、收音 false、恢复原回应暂停。

明显待改：同一会议故事连续点评三次，规则/语音识别梗重复；其中“关了摄像头”的复述丢失了观众原话“以为”的限定。未来应减少重复并准确保留事实，不用更多推理轮来补偿。

## 结果与限制

- 前三段约7分钟，续测约4分钟，合计约11分钟。12条语音完整播出、1条合成/播放失败、1条被模拟主播插话取消；不是连续11分钟无故障。中间调试、部署与隔离模型检查不计入。
- 正常接弹幕、主播说先讲完后等待、拒绝观众覆盖主播叫停、普通应和不打断播放均有实际桌面记录。明确叫停发生在上一句播完后，这次不据此宣称测过语音中途停止延迟。
- 第3段检测到用户开启麦克风并有脚本外输入，已暂停注入；得到用户确认“继续帮我模拟，我暂时不说话”后进行第4段。记录不收录真人输入内容。
- 模型会受旧话题影响，也出现过把观众的购买玩笑归给主播。已补来源规则，但尚未证明所有归属错误消失。
- 发现静默机会试图重答旧主播话，未执行；已将工具动作枚举限制为本轮有效动作，并通过回归。
- 百炼一次启动超时，重试成功；一次合成／播放失败，自动主持随之暂停。未更换音色，网络与长连接稳定性仍需改善。
