## 直接模拟直播

1. 刷新 http://127.0.0.1:8787 。本机服务默认自动导演、真实 DeepSeek、自主参与（已配置密钥时）和弹幕回复窗口。
2. 右侧选“主播说话”，选一句示例或输入自己的话，点“说完这句，发送”。小鲸鱼自行决定接话、文字/表情回应或等待。
3. 要模拟持续讲话，勾选“我还在说，先别接话”；取消勾选或发送这句表示说完。这是文字活动模拟，不是语音识别。
4. 切到“观众弹幕”，选一条或自写一条，再点“发送弹幕”。可开启每 5 秒来一条弹幕，或开关小鲸鱼回复弹幕。未指定昵称时轮换模拟观众。
5. 随时点“让小鲸鱼停一下”打断。Ctrl / ⌘ + Enter 可发送当前输入。
6. “更多设置”收纳人工导演、回复来源、自主参与开关、暂停回应、人工接话、弹幕身份与候选、开发调试和清空。正常排练无需展开。
7. 中间聊天保留主播、弹幕及小鲸鱼同角色的导演决定/回复，按时间排列。文字/表情回应单独标记；打断片段保留并标明状态。
8. 本场展示记录在服务端内存保留最近 300 条。刷新或其他标签页可继续看；服务重启或清空会结束本场。展示记录与模型上下文分开，不是长期记忆。

## 启动

在 Windows 项目目录执行：

```powershell
.\scripts\setup-local.ps1
.\scripts\local.ps1 check
.\scripts\local.ps1 test
.\scripts\local.ps1 setup:airi:web
```

当前任务将两项服务在后台启动。停止本任务的后台服务可执行 scripts/stop-local.ps1，它会核验进程身份。常规开发时分别在两个终端执行：

```powershell
.\scripts\local.ps1 dev
.\scripts\local.ps1 dev:airi
```

打开 http://127.0.0.1:8787 。左侧嵌入 http://127.0.0.1:5173 的 AIRI 网页舞台，回复字幕由 cohost 显示。首次使用 AIRI 时跳过供应商引导并选择默认形象即可。不要把 DeepSeek 密钥填写到 AIRI 网页；本轮调用经 cohost 服务端完成。

工具链安装在忽略的 data/toolchains，不修改系统 Node。安装脚本核验 Node 官方 SHA256，复用已安装的固定版本，不覆盖已有 .env。npm 11.19.0、pnpm 11.24.0 和 Node 26.7.0 与交接一致。

AIRI 安装只覆盖 stage-web 及工作区依赖，跳过安装生命周期脚本，再构建内部依赖。上游可能带入桌面相关依赖，但本轮没有安装 Electron 应用、运行桌面端或验收原生能力。获取源码前检查远端和工作树，开发启动检查固定 HEAD。

## 相同条件的导演对照

1. 默认真实 DeepSeek。在本机 .env 配置密钥并重启后，直接发送主播话即可排练；“更多设置 → 开发调试”仍保留一键试聊。“先看模拟效果”无需密钥，使用固定时机样例，不能用于内容质量或模型延迟评估。
2. 在“更多设置”切换人工模式后，“说完这句，发送”只提交主播发言。点击“人工让助播接话”才生成。
3. 切换自动模式，使用同一回复来源、模型和人设。“助播，你怎么看？”在最终文本与结束事件齐全后立即消费决定。
4. 句中停顿、未点名话题没有足够证据时保持等待。短附和保留正在生成的回答；精确的“等一下”取消当前话轮。
5. 可选择预设弹幕、自定义弹幕或打开定时模拟。人工点选提高优先级；自动回复须另外开启“自动导演允许回复弹幕”。
6. 弹幕受主播活动、静音、忙碌、全局/观众冷却和过期限制。话题切换清空旧弹幕、关闭弹幕窗口。
7. 复杂交棒、接管和主动补充暂用折叠面板中的“模拟语义”。这些意图由操作者指定，不能当作真实语义识别验收。

自动消费由打开的浏览器页面运行。每 400 ms 刷新状态以获取异步结果，但明确交棒直接使用事件返回值，不等待轮询，也不增加生成前的第二次模型调用。多标签页重复消费会被服务端拒绝，过期或作废决定不调用生成模型。

真实 API 在本机 .env 配置 DEEPSEEK_API_KEY 后重启 cohost，再选择 DeepSeek。两种导演调用同一 streamReply、系统提示与 DEEPSEEK_MODEL。模拟与真实 API 的服务端历史分开保存，避免用样例污染真实对话；重置会同时清空两种历史。

## 时间线和验收

聊天时间线显示主播输入、弹幕、同角色导演决定和每轮回复。气泡与舞台的“生成首字”从服务端开始生成计时；折叠的请求记录另记浏览器请求首字。均不是 ASR、TTS 或实际出声延迟。

新增导演事件：

```json
{"type":"viewer-window","value":true}
```

状态接口返回有稳定序号的最近 100 条导演 trace、最多 128 条弹幕队列，以及 room 中本场最近 300 条展示消息。room.session 随清空/重启改变，条目有稳定 id 和递增 revision，流式 start/delta/终止事件携带对应 entry 与 session。选中已存在弹幕用 POST /api/danmaku/select，携带 id/platform，不用重复入队。

可选浏览器回归命令：

```powershell
# 使用已安装的 Playwright。必要时设置 PLAYWRIGHT_MODULE 为该模块的 file:///.../index.mjs。
node scripts/browser-smoke.mjs
```

测试启动独立随机端口 cohost，使用无密钥模拟回复与独立 Edge 会话，不修改正在运行的直播间。覆盖人工/自动模式、停顿、打断、弹幕窗口、话题切换、同角色气泡、顺序与文本转义、刷新/多标签页历史、清空和 390 px 布局；截图保存至忽略的 data/。

## 当前边界

AIRI 在 iframe 内独立渲染；字幕在舞台下方单独展示，不覆盖舞台操作。点击“放大舞台”可操作更大范围的设置页。尚未将回复注入 AIRI 的聊天或语音运行时，没有 TTS、播放门控、口型/情绪同步、真实语音或长期记忆。看到 iframe 加载事件或空 canvas 不算形象渲染成功，须核对截图、模型资源与控制台。


## 自主参与更新（2026-10-10）

自动导演现在可开启“自主参与 · DeepSeek”，由同一助播选择等待、接话和相关弹幕，理由显示为聊天气泡。明确交棒仍直接流式回答；模拟回复会关闭自主判断。最短三步测试、实际结果与限制见 [文字自主参与](AUTONOMOUS-PARTICIPATION.md)。
