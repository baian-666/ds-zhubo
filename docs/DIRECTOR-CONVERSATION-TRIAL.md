# 当前导演自然参与试验

日期：2026-10-10。代码基线：5f8344e。使用现有导演和真实 deepseek-flash，未修改判断规则，也未提交人工模拟 intent。

结论：当前自动导演不具备基于完整现场上下文的自主参与能力。它能执行部分固定交棒、停止、附和和弹幕门控规则，但语义分类器未接入。聊天中的第一人称导演说明是规则对应文案，不是模型主动观察后的判断。

## 测试方式

- 独立本地服务 8788，原 8787 场次不变。按正常 HTTP 事件发送主播最终文本、结束讲话和模拟弹幕；有合法候选时立即消费，等同网页的自动消费路径。
- 13 个连续步骤，真实 DeepSeek 完成 3 次回答。主播文字输入只是文字排练，没有真人语音或实际出声。
- “嗯，对 / 等一下长句 / 等一下”另用模拟在途话轮做同步规则探针；这部分没有真实音频，也不代表真实停止播放验证。
- 完整脚本：tests/fixtures/director-conversation.json；可复跑程序：scripts/director-conversation-trial.mjs。
- 默认运行使用模拟回复；加 --real 并通过本机忽略 .env 加载密钥才进行真实调用。--serve 在 127.0.0.1:8788 保留试验气泡。后台 PID 保存于 data/director-trial.pid，入口为 scripts/director-conversation-trial.mjs。

## 连续对话与实际结果

| 场景 | 输入摘要 | 实际行为 |
|---|---|---|
| 铺垫 | 主播：“我的猫叫年糕，它每天霸占跑步机。” | 等待，没有生成 |
| 相关弹幕 | 团子：“你买的是猫的观景台吧！” | 等待，没有生成 |
| 自然抛梗 | 主播：“猫看风景，我晾衣服，这算不算一机两用？” | 等待，没有生成 |
| 自然问句 | 主播：“你说我是不是该给它改名叫晾衣机？” | 等待 1.5 秒后仍无候选 |
| 明确交棒换措辞 | 主播：“助播，帮我总结一下大家刚才在笑什么。” | 漏接，仍称没有交棒证据 |
| 固定句式交棒 | 主播：“助播，你觉得把跑步机用来晾衣服这件事好笑吗？” | 接话，真实 DeepSeek 回复 |
| 短附和 | 主播：“嗯，对” | 识别为短附和，不新增回答 |
| 回忆现场信息 | 主播：“助播，你觉得我刚才提到的那只猫叫什么名字？” | 接话，但模型不知道猫名 |
| 继续当前话题 | 主播：“接下来想说怎么坚持运动。” | 等待，没有生成 |
| 先到的偏题弹幕 | 路人甲：“助播，推荐一款手机吧。” | 入队，窗口关闭时等待 |
| 后到的相关弹幕 | 运动小白：“跑步机总闲置，有什么办法坚持运动？” | 入队，窗口关闭时等待 |
| 打开弹幕窗口 | 两条可答弹幕同时存在 | 选先到的手机问题，没有比较话题相关性 |
| 结束试验 | 关闭弹幕窗口 | 停止自动消费候选 |

这些场景不是统计意义上的自然互动评测，不能将 3 次生成除以 13 步当作成功率；铺垫、附和和关闭窗口本就不需要回复。明确交棒漏接、现场上下文缺失和不按相关性选择弹幕则有直接证据。

## 三次真实回复

1. 对跑步机晾衣服：“挺好笑的，但我觉得它更像是一种诚实。买的时候都想着天天跑，最后发现它最稳定的功能就是当晾衣架。”
2. 问猫名：“这个我真没法接，刚才的聊天里没提到过猫的名字，你再说一遍我就记住了。”
3. 对手机问题：“这个得看你的预算和用途，我随便报个型号反而容易带偏你，不如先说说是拍照多还是打游戏多。”

第二次请求实际传给模型的历史只有 2 条消息，即此前一问一答，不包含“年糕”。这证明问题发生在现场上下文接入，不能归因于 DeepSeek 记忆能力。界面里可见的聊天记录并不等于模型收到的上下文。

## 打断与附和规则探针

| 主播文字 | 意图 | 在途话轮 |
|---|---|---|
| 嗯，对 | backchannel | 保留 |
| 等一下，我还没说完，先让我补充一个细节。 | hold | 没有打断 |
| 等一下 | stop | 成功取消 |

## 为什么会这样

- Director 构造时 classify 默认为 null，createApp 没有提供语义适配器。主动补充 opportunity 目前需要外部提交模拟意图。
- 交棒正则要求“助播”开头且后面含“你怎么看 / 你觉得 / 你来说 / 你来回答 / 帮我解释 / 说说你的看法”。“帮我总结”不匹配。
- 停止短语采用整句精确匹配；“等一下”后继续解释就无法命中。
- 弹幕依据 mentioned/selected 标记、空闲、窗口、过期和冷却筛选；排序是人工选中优先，然后按到达顺序，没有相关性或价值判断。
- 模型上下文只积累已完成回答所对应的一问一答；尚未回复的主播话、未选中弹幕没有进入模型上下文。RoomJournal 仅作展示。

## 接下来应改什么

先把最近的主播发言与弹幕组成有界现场上下文，再让同一角色基于现场异步判断“等待 / 接话 / 接梗 / 回复哪条 / 接管停止”，给出可审阅的简短决定。规则保留明确停止与快速交棒；普通回答路径不串行等待第二次模型调用。继续使用本测例做前后对照，避免只增加触发词就声称实现了自然主动参与。
