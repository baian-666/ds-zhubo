# 导演能力手册与搭档反馈

2026-10-18。手册已改为桌面原生设置，并接入信息 MCP。当前部署编号见 [STATUS](STATUS.md)。

## 使用

开启原有自主参与后，在正常主播文字/语音对话中直接提出指导：

- “这个地方要更活泼一点。”结合前文保存对应场景，不自动变成所有场合都亢奋。
- “以后少用反问句，多直接讲自己的看法。”作为长期整体偏好。
- “只限这场，介绍规则时讲慢一点。”作为临时反馈，清空本场或重启后移除。
- “刚才那条活泼的要求改一下，轻松接梗就行，不要夸张喊叫。”修正已有条目。
- “把刚才记的轻松接梗那条要求取消。”移除对应反馈。

保存结果以导演时间线的“导演手册已保存”或失败提示为准，不以生成台词里的承诺为准。
打开桌面直播间「设置 → 直播助播 → 导演手册与信息查询」，可查看能力说明、反馈原话、已交付上下文，或添加、修改、移除反馈。这个组件直接在 AIRI 设置窗口内渲染；旧 `/director-handbook` 独立网页与入口已移除。
自动记录开关作用于全部角色；条目按角色卡隔离。关闭自动记录仍可读已有反馈、手动编辑。

同一处可检查 MCP 连接、查看本场最近查询和来源。无需另外配置账号即可先使用 Exa 的匿名公开服务；有服务限流，不保证每个网址都能读取。连接状态写“上次连接成功”，不是持续在线承诺。

- “查一下国际天文学联合会为什么把冥王星归为矮行星。”按需公开搜索。
- “读一下这个网页，帮我概括要点：……”只接受主播提供或本轮搜索得到的公开地址。
- “读一下当前直播现场状态。”本机 MCP 读取现场，不能看屏幕或操作游戏。

普通闲聊直接生成回答，查询由同一个导演模型选择，最多3次/轮、总判断期限30秒；新的插话、停止、静音、切角色会取消旧工作。查询失败有回执，模型不得声称已读到失败网页。[协议与验证](DIRECTOR-MCP.md)。

## 实现

固定手册：[director-manual.md](../apps/cohost/director-manual.md)。真实注入导演参与请求，说明参与/让话、声音、表情组件、素材、待续事项与反馈写入。具体能力、参数范围、权限、版本仍来自本轮工具与动态目录。
`participate`仍是统一行动出口。信息工具使用官方 MCP SDK，连接本机现场服务器及 Exa 的远程 Streamable HTTP 服务；有真实 initialize、tools/list、tools/call。先查资料，再回到原来的台词/动作流，不把远程工具目录直接变成任意执行权限。

反馈：[director-handbook.mjs](../apps/cohost/director-handbook.mjs)。SQLite `module_settings/director-handbook`独立于场次检查点，SQL版本仍为3。长期条目不被“清空本场”删除，临时条目会。每角色24条、全局192条；满时提示整理，不自动删旧条目。每轮注入当前角色有界条目，无向量检索。

- 同一次导演调用输出coaching，无新增串行模型请求。reply_*放在台词后的presentation，首句先出；wait/react/stop随decision提交。手册增加输入token，不声称绝对零延迟。
- 写入绑定当前最终主播输入、完整原话、角色、场次、手册修订和提供的条目ID。临时ASR、边听预备、完整回答预备、观众机会、旧历史不得写入。
- 语义判断由模型完成，程序校验来源及版本。不是固定“活泼”关键词匹配，也不是模型训练或无限自我反思。
- 流式生成成功完成后保存，不等TTS播完；记录的是已收到的主播指导，不是“回答已播完”。取消/失败/新输入/切角色/手工编辑后，旧结果不得写回。存储成功前不更新内存，失败明确回执。
- 静音、暂停、权限和动作范围仍由程序执行。偏好不授予新权限，不改系统提示词或任意文件。固定手册由开发者维护，自动更新的是反馈页。
- 原生设置/API复用访问令牌与同源控制；编辑有修订冲突保护，自动刷新保留同一角色草稿，切角色丢弃旧草稿。原话和反馈按文本渲染，不执行HTML。
