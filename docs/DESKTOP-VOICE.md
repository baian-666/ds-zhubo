# 本机桌面与语音试播

更新：2026-10-12。桌面为日常主入口，网页备用。新的侧栏与设置边界见 [AIRI 本机直播入口](AIRI-CONSOLE.md)。真人自然话轮仍待验收。

## 开始试播

1. 在项目目录双击 `启动小鲸鱼.cmd`，打开桌面 AIRI 直播侧栏；网页备用双击 `启动网页版.cmd`。
2. 戴耳机，确认默认麦克风是要使用的设备。
3. 侧栏自动使用当前舞台的 AIRI 云端语音，两端只有一个收音和发声。
4. 等“开始收音”可用后点击。首次加载 VAD 可以多等一会。
5. 等状态显示“正在收音”，说一句话并停顿。最终识别文字和回复进入右侧聊天。
6. 小鲸鱼自动决定接话并解释理由。人工对照移到 [开发入口](http://127.0.0.1:8787/?debug)。
7. “停一下”停止当前回复、合成和播放。“停止收音”同时释放麦克风。收起聊天不会主动停收音。

首次可以说：“小鲸鱼，你觉得今天这个故事怎么样？”
若名字识别错误，或没有明显交棒证据，导演可以等待。可查看中间气泡的公开理由。
完整耗时仍在服务端时间线和开发入口中，识别、生成与播放回执不是同一指标。

首次使用必须允许 AIRI 舞台访问麦克风。网页嵌入舞台已设置 microphone 和 autoplay 权限。
服务不会自行开麦。失败或断线会停收音，需要再次手动开启。
默认声音为 CosyVoice2 的 claire。自定义音色按用户决定后置。

## 凭据与数据

硅基流动 API 密钥仅放本机忽略的 .env。AIRI 不需要再填写云服务密钥。
./scripts/local.ps1 configure:voice 启动一次性配置页 [8789](http://127.0.0.1:8789/)。
保存后配置页关闭。修改密钥后重启 cohost，舞台不需要保存它。
DeepSeek 保留已有配置，识别不会触发 AIRI 默认聊天生成第二轮回复。

AIRI 在本机检测语音活动并切句。所选录音片段会上传硅基流动识别，主播文字发给 DeepSeek。
真人麦克风录音不自动写文件。开发合成样本和测试报告放在忽略 data 目录。
这是分段上传识别，不是实时流式 ASR。请戴耳机，外放回声消除未经过真人验收。

## 启动与停止

在仓库 PowerShell 中，分别启动：

~~~powershell
./scripts/local.ps1 dev
./scripts/local.ps1 dev:airi
./scripts/local.ps1 dev:desktop
~~~

首次安装桌面依赖用 ./scripts/local.ps1 setup:desktop。
桌面配置在忽略 data/desktop-profile，与其他 AIRI 配置隔离。
本机语音代理固定连接 127.0.0.1:8787，网页舞台 5173，桌面开发舞台 5174。
舞台源码变更保存在 integrations/airi，通过脚本应用，不只留在 vendor。
scripts/stop-local.ps1 校验 PID 与可执行文件后停止本次开发服务。

## Windows 备用链路

在开发入口选择“Windows 系统语音（备用）”后，在收音前选择是否使用系统声音回答。
它使用 System.Speech 中文听写，整段文字生成后系统朗读，不带 AIRI 音频口型。
低置信度文字需要检查后发送。备用与 AIRI 不能同时开启。
这条链路的录音不上传硅基流动，识别文字仍发送 DeepSeek。

## 当前边界与验证

- AIRI 原生麦克风管理、650 ms VAD 切句、兼容识别适配和分句播放已连接。只有 cohost 执行导演及回复。
- 自动执行在服务端运行。控制台用于显示和控制，不需要靠其轮询触发语音回答。
- 当前音频实际播放驱动默认 Live2D 口型。只确认已完成音频片段的原文前缀，打断不把未播文字写入模型历史。
- 一个舞台拥有会话，其他舞台不能抢占。舞台约 3.5 秒失联服务端取消会话，本机约 2.5 秒失联停收音和播放。
- 网页后台计时器仍有被浏览器降频的风险，优先使用桌面舞台。窗口独占不是操作系统层面的全局麦克风锁。
- 已验证合成麦克风与模拟供应商闭环、分句播放、口型随播放变化和停播归零。单次按钮停播 210 ms，不代表真人长时段统计。
- 真实服务小样本 ASR 曾耗时 10.5 秒并把“小鲸鱼”听成“小金鱼”，TTS 短句生成约 0.8 秒。真人准确率、口头打断和端到端接话速度仍待测。
- 鲸鱼娘已在两端实际渲染，四组专属表情与连续表演已验证，见 LIVE2D-PERFORMANCE 与 STATUS。
- 未接平台弹幕、OBS、视觉或自定义音色，未打包桌面安装程序。
