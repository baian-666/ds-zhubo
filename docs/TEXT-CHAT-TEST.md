# 文字聊天测试准备

更新：2026-10-07。用户已授权少量真实文字调用，已完成两次极短生成验证。尚未验证用户浏览器入口。

## 开始条件

1. 读取当前环境观测；仅当状态分别为 `ready/enforced` 才把运行时标记记为就绪。2026-10-07 排查后这两个状态仍是 `unknown`，但通过环境代理请求模型列表和两次极短生成均为 HTTP 200，已分别确认实际鉴权与聊天链路可用。状态标记与实测结果分开记录。
2. 用户已授权本轮少量真实文字调用，不自动重试或循环调用。
3. 模型列表及生成已确认 `deepseek-flash` 可用，关闭 thinking 的参数也已验证；可通过 `DEEPSEEK_MODEL` 设置模型，本轮未使用 `deepseek-v4-pro`。

`/api/status` 的 `deepseekConfigured` 仅表示变量存在，不能证明运行时凭据 ready。根路径 HEAD 返回 401 只用于证明无凭据请求的连通性。

## 启动与范围

2026-10-07 的真实调用记录使用 Node 24.19.0；后续开发统一使用已保存的 Node 26.7.0。必须启用环境代理以保持网络密钥注入路径：在仓库根目录运行 `node --use-env-proxy --env-file-if-exists=.env apps/cohost/server.mjs`，默认仅监听 `127.0.0.1:8787`。使用环境提供的安全端口预览；当前工具未提供端口转发地址，浏览器打开动作仅返回 queued，用户入口仍未验证。不要把云环境的 localhost 地址当作用户电脑可直接访问的地址。若确需非本机监听，先通过 secrets 配置至少 24 字符的 `COHOST_ACCESS_TOKEN`，不要把模型密钥放进网页、URL、命令行或文件。不要为测试直接公开无鉴权服务。

先用 `GET /healthz`、`GET /api/status` 和页面确认服务正常；这些路由不调用模型。设置了访问令牌时，控制 API 需要访问令牌。

真实测试按下表逐项操作，不自动重试或循环调用。每个回答最多 256 tokens，请求时限 30 秒；上下文保留最近 12 条消息。先验证三轮人工交棒，再按需要验证弹幕、静音和取消。

| 场景 | 操作 | 观察 |
|---|---|---|
| 打招呼 | 主播输入“今天一起聊聊下班后怎么放松，你先打个招呼。” | 中文一到两句，口语自然，不输出思考过程 |
| 连续对话 | 输入“我更喜欢散步，接着刚才的话题聊一句。” | 使用上一轮上下文，不重复开场 |
| 知识分享 | 输入“用两句口语解释为什么睡前少看手机可能有帮助。” | 简短，不编造来源或夸大结论 |
| 模拟弹幕 | 加入一条点名或手动选中的相关弹幕，点击挑一条回复 | 仅候选入队不收费，挑选回复会调用模型；观察冷却与队列 |
| 静音 | 静音后请求回复 | 保持安静，不发起模型请求 |
| 打断 | 在生成期间点击打断或切换主播讲话 | 输出 cancelled，旧话轮后续片段不再显示；已开始的调用可能已产生费用 |

2026-10-09 已增加导演事件原型：原手动讲话按钮仍是明确让话指令，新的原始语音活动事件不直接取消；复杂语义判断尚需适配器，参见 `TURN-DIRECTOR.md`。没有 ASR、TTS、Live2D 或真实平台弹幕，文字取消不代表音频停声已验证。
