# 文字聊天测试准备

更新：2026-10-07。本轮仅准备，没有调用真实聊天 API。

## 开始条件

1. 环境状态工具返回当前观测，`DEEPSEEK_API_KEY` 为 `ready`，网络策略为 `enforced`，允许 `api.deepseek.com`。2026-10-07 检查时这两个状态仍是 `unknown`。
2. 用户授权本轮真实文字调用。目前授权仅为检查和准备，不包含付费 API 调用。
3. 确认实际支持的模型；当前代码默认 `deepseek-flash`，可通过 `DEEPSEEK_MODEL` 设置。当前模型名称与请求中的 `thinking` 参数尚未经过真实 API 验证。

`/api/status` 的 `deepseekConfigured` 仅表示变量存在，不能证明运行时凭据 ready。根路径 HEAD 返回 401 只用于证明无凭据请求的连通性。

## 启动与范围

在仓库根目录运行 `npm run dev`，默认仅监听 `127.0.0.1:8787`。使用环境提供的安全端口预览；尚未验证本环境的浏览器预览能力。若确需非本机监听，先通过 secrets 配置至少 24 字符的 `COHOST_ACCESS_TOKEN`，不要把模型密钥放进网页、URL、命令行或文件。不要为测试直接公开无鉴权服务。

先用 `GET /healthz`、`GET /api/status` 和页面确认服务正常；这些路由不调用模型。设置了访问令牌时，控制 API 需要访问令牌。

真实测试按下表逐项操作，不自动重试或循环调用。每个回答最多 256 tokens，请求时限 30 秒；上下文保留最近 12 条消息。先验证三轮人工交棒，再按需要验证弹幕、静音和取消。

| 场景 | 操作 | 观察 |
|---|---|---|
| 打招呼 | 主播输入“今天一起聊聊下班后怎么放松，你先打个招呼。” | 中文一到两句，口语自然，不输出思考过程 |
| 连续对话 | 输入“我更喜欢散步，接着刚才的话题聊一句。” | 使用上一轮上下文，不重复开场 |
| 知识分享 | 输入“用两句口语解释为什么睡前少看手机可能有帮助。” | 简短，不编造来源或夸大结论 |
| 模拟弹幕 | 加入一条点名或手动选中的相关弹幕，点击挑一条回复 | 仅候选入队不收费，挑选回复会调用模型；观察冷却与队列 |
| 静音 | 静音后请求回复 | 保持安静，不发起模型请求 |
| 打断 | 在生成期间点击打断或切换主播讲话 | 输出 cancelled，旧话轮后续片段不再显示；已开始的调用可能已产生费用 |

这是手动文字原型。当前“主播讲话即取消”规则仍待升级；没有 ASR、TTS、Live2D 或真实平台弹幕，文字取消不代表音频停声已验证。
