# AIRI 本机直播入口

更新：2026-10-12。日常使用桌面端，网页作为备用。

## 打开与使用

在项目目录双击 `启动小鲸鱼.cmd`。它复用已有直播服务和桌面窗口，缺少服务时自动启动，不清空运行中的场次。桌面仍是开发版，尚未制作安装包。

网页备用双击 `启动网页版.cmd`，或在服务已启动时打开 http://127.0.0.1:5173/?cohost 。网页版使用同一侧栏与直播服务。

日常操作：

1. 选择“主播”或“观众”，写一句话并发送。Ctrl + Enter 也可发送。
2. 聊天气泡按时间显示主播、模拟弹幕、小鲸鱼回复和公开的导演理由。导演与助播是同一角色。
3. “停一下”立即取消当前回答；“暂停回应”暂时阻止新回答。
4. 戴耳机后点击“开始收音”。“停止收音”释放本侧栏开启的麦克风。
5. 右上角收起聊天会留出完整舞台，不会关闭侧栏组件或主动停止收音。真实收音时的长期稳定性仍需试播。

主播和观众有各自的草稿，切换不会丢掉尚未发送的文字。两边同时打开时共享同一场次，服务端只消费一次接话机会。语音仍只允许一个舞台拥有会话。

预设测试句、导演切换、回复来源、模拟语义和 Windows 备用语音移到开发入口 http://127.0.0.1:8787/?debug 。普通 8787 页面也已精简。日常入口固定使用真实 DeepSeek、自然参与和允许合适的弹幕回应。

## 哪些设置生效

“当前配置”显示直播服务实际使用的人格、回复模型、识别模型、合成模型与音色。两端读取同一配置，不另建聊天引擎。

- AIRI 的形象选择、缩放、位置、原生表情与主题外观继续生效，鼠标眼神跟随仍按此前要求关闭。
- 直播回复使用 cohost 服务的 DeepSeek 和“小鲸鱼”人格，语音沿用 AIRI 原生识别适配、分句播放与口型。AIRI 原生聊天的供应商和人格卡不覆盖直播配置。
- 目前不是 AIRI 全部设置的双向同步。桌面和网页的外观偏好分别保存在各自本机配置中，直播现场、聊天和控制状态共享。
- 麦克风使用系统默认设备。AIRI 原生麦克风选择尚未接入本直播控制。
- 供应商密钥只保存在忽略的 `.env`。侧栏不会复制密钥到 AIRI 配置；可选助播访问令牌只在侧栏内存中使用。

## 开发与复现

固定端口：直播服务 127.0.0.1:8787，网页 127.0.0.1:5173，桌面 localhost:5174，桌面调试仅在回环 9250。

桌面固定使用原来的 localhost 地址，保留原有角色数据库。独立启动不会再占用网页端口。窗口初始大小受显示器工作区限制，侧栏不再压在角色上。

共享组件、文本和适配保存在 `integrations/airi`。`scripts/patch-console.mjs` 将组件安装到 AIRI stage-ui，并为两端挂载入口。`patch-airi.mjs` 和 `patch-desktop.mjs` 重放固定版本的修改，拒绝覆盖未保存的自有组件改动。

在已有本机环境复查：

```powershell
./scripts/local.ps1 check
./scripts/local.ps1 test
# 两个舞台启动后，使用已安装的 Playwright 运行：
node scripts/native-console-smoke.mjs
```

最后一项使用同一个模拟后端连接实际网页与 Electron 界面，检查一次回复、跨窗口打断、草稿、折叠、配置、暂停同步和小屏操作。测试截图和结果保存在忽略的 data 目录。模型服务未被实际调用，不采集真人麦克风。具体检查结果与现有全仓依赖阻塞见 STATUS 最新记录。

启动日志位于 `data/start-desktop.log`、`data/start-web.log` 及对应服务日志。`scripts/stop-local.ps1` 通过保存的 PID 和入口身份检查停止服务。服务端仍是进程内场次，重启前需备份聊天；长期记忆、正式直播平台和安装包继续后置。
