# 本场待续想法

更新：2026-10-12。桌面和网页共用本机导演，正常聊天即可使用，不增加日常设置。

小鲸鱼可以在原来的参与决定中暂存一条公开意图。例如主播还没讲完跑步机的故事，她先记着“年糕才是房东”这个梗。它不是已说过的台词，不作为现场事实，也不是私密思维链。

- `wait/react` 可带 `thought:{text,wake}`，意图最多 120 字，仅一条，后来的替换前面的，45 秒过期。
- `next_host_turn` 等下一句主播话，带入自主判断或明确交棒的快速生成，由模型决定自然接回还是略过。安静时不反复调用模型。
- `after_reply` 只在确实有活动回复时创建；对应回复必须正常完整交付，播放失败、取消或仅完成生成不会释放这个机会。等实际完成后安静至少 1200 ms、主播未讲话、无活动回复且主动冷却通过，最多额外复查一次。这个调用在后续空档发生，不串行加在原回答前；仍有 token 与调用成本。
- 复查通过 `reply_followup` 与相同便签编号拟好一条短台词，执行前再次检查状态、有效期和编号；直接使用准备好的台词，不再二次生成。复查可选择 `wait` 丢掉，不能创建新便签形成循环。失败或被新主播话打断，也不反复自动复查。
- 换话题、暂停/静音、叫停、停止收音、重置及断联停收音清除意图；它不跨进程恢复，不是长期记忆。新主播话到来时不会仅凭旧便签出声。

聊天中的导演气泡会说明“我先记着这个想法”或接回的公开理由。模型可以普通等待而不存便签，也可以后来觉得不值得说；不强制每轮演戏或兑现旧梗。

独立测试（不改正在使用的场次）：

```powershell
node scripts/continuity-trial.mjs
node scripts/browser-continuity-smoke.mjs
# 真实 DeepSeek，所有对话新编，不读取用户旧聊天；需要本机 .env
node --env-file-if-exists=.env scripts/continuity-trial.mjs --real
```

浏览器脚本需要已安装的 Playwright、运行中的网页 5173 和桌面调试口 9250；通过 `PLAYWRIGHT_MODULE` 指向已配置模块。实际两端 UI 回归使用独立模拟后端，退出恢复原场次与聊天折叠状态，不开真人麦克风。长对话模拟结果、真实模型结果与浏览器证据分别保存于忽略的 `data/continuity-*`。

已验证：程序一次复查、同编号消费、实际播放完成门槛、晚到结果、过期/暂停/换题、快速路径携带意图；两端 UI 合成回归；虚构长对话的真实模型等待/接梗/跨题回忆，以及明确要求暂存的真实样本。自然主动保存的频率、真实语音空档、抢话率、连续情绪、长期共同记忆仍待试播评估。
